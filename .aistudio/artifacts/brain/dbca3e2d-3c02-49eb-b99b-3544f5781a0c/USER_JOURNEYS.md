# User Journeys: Cardios Platform

## 1. Doctor Workflow (Clinical Encounter & Management)
1.  **Patient Arrival**: Doctor opens the Patient Dashboard (EHR-01).
2.  **Lab Check**: If patient underwent tests, Doctor clicks "Sync Results" (LAB-02). Data auto-populates.
3.  **Consultation**: Doctor records encounter notes using cardiac templates (EHR-04) and reviews vitals trends from RPM module (RPM-04).
4.  **Prescription**: Doctor updates medications (RPM-02/Smart Prescriptions).
5.  **Follow-up**: System schedules next appointment and sets RPM monitoring parameters based on visit outcome.

## 2. Patient Workflow (Remote Monitoring)
1.  **Data Log**: Patient receives notification, logs BP/Heart Rate in the app (RPM-01).
2.  **Medication Adherence**: Patient confirms dose intake (RPM-02).
3.  **Result Access**: Patient receives push notification when lab/scan results are ready (LAB-02).
4.  **Alerts**: If vitals are outside defined thresholds, Patient receives automated guidance to contact the clinic (RPM-03).
